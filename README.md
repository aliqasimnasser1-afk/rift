# RIFT — بوابة بين الجوال والكمبيوتر

موقع لإرسال الصور والفيديو والملفات والمجلدات والنصوص بين الجوال والكمبيوتر، في الاتجاهين.
الملفات تنتقل **مباشرة** بين الجهازين عبر WebRTC (مكتبة [PeerJS](https://peerjs.com)) — ما ترتفع على أي سيرفر.
الموقع ملفات ثابتة فقط (HTML/CSS/JS)، فيشتغل على GitHub Pages بدون أي باك-إند.

## طريقة الاستخدام

1. افتح الموقع على الكمبيوتر — يطلع لك QR ورمز من 6 خانات.
2. امسح الـ QR بكاميرا الجوال (أو افتح الموقع في الجوال واكتب الرمز).
3. بعد ما يطلع «متصل ✓» أرسل أي شي من أي جهاز للثاني.

بعد أول ربط، الجهازين يتذكرون بعض، والمرات الجاية يتصلون تلقائيًا أول ما تفتح الموقع عليهم.

## المميزات

- **دخولية سينمائية:** خط ضوء ينشق لبوابة، ثم يطلع اللوقو والاسم وتدخل الصفحة.
- **أجهزة موثوقة:** اتصال تلقائي بدون QR بعد أول مرة، وتقدر تنسى أي جهاز.
- **يكمل من وين وقف:** إذا انقطع الاتصال وسط ملف، يرجع يتصل تلقائيًا ويكمل من نفس النقطة.
- **الحفظ على القرص:** الملف المستلم ينكتب على تخزين المتصفح (OPFS) وهو يوصل بدل الذاكرة. وعلى Chrome وEdge بالكمبيوتر تقدر تختار مجلد يُحفظ فيه كل شي تلقائيًا.
- **إرسال مجلد كامل:** يوصل للطرف الثاني ملف ZIP واحد، بالزر أو بالسحب والإفلات.
- **ضغط اختياري:** للصور (حتى 2560px) وللفيديو.
- **قنوات متوازية:** 4 قنوات بيانات بنفس الوقت.
- **أنيميشن:** الملف يطير داخل الشعاع من جهاز للثاني.
- **معرض:** شبكة للصور والفيديو المستلمة، وعارض بملء الشاشة تقلب فيه بالسحب أو الأسهم.
- **إشعارات:** إشعارات النظام، وصوت واهتزاز.
- **لغتين:** عربي (افتراضي) وإنجليزي، والاتجاه يتغير تلقائيًا.
- **كل الشاشات:** جوال صغير، جوال أفقي، تابلت، كمبيوتر، وشاشات 2K/4K.
- **PWA:** يقدر ينضاف للشاشة الرئيسية كتطبيق.

## الملفات

| الملف | الدور |
|---|---|
| `index.html` | الهيكل والدخولية |
| `style.css` | التصميم وكل مقاسات الشاشات |
| `app.js` | الاتصال والنقل والإكمال والحفظ والمعرض |
| `i18n.js` | النصوص بالعربي والإنجليزي |
| `sw.js` | Service Worker للإشعارات والتثبيت |
| `favicon.svg`، `manifest.webmanifest` | الأيقونة وبيانات التطبيق |

## النشر على GitHub Pages

1. أنشئ مستودع جديد على GitHub (مثلاً `rift`).
2. ارفع كل الملفات اللي فوق.
3. من المستودع: **Settings → Pages → Source: Deploy from a branch → Branch: `main` / `(root)`** ثم Save.
4. بعد دقيقة يصير الموقع على: `https://<اسمك>.github.io/rift/`

أو من الطرفية (يحتاج `gh`):

```bash
git init && git add index.html style.css app.js i18n.js sw.js favicon.svg manifest.webmanifest README.md && git commit -m "RIFT"
gh repo create rift --public --source=. --push
gh api -X POST repos/{owner}/rift/pages -f "source[branch]=main" -f "source[path]=/"
```

## ملاحظات

- يحتاج إنترنت على الجهازين للربط الأولي عبر سيرفر PeerJS المجاني.
- أسرع شي لما يكون الجهازين على نفس الواي فاي. بعض شبكات الجوال تمنع الاتصال المباشر.
- إكمال الملف بعد تحديث صفحة **المرسل** يحتاج تختار نفس الملف مرة ثانية، والمستلم يكمل من الجزء اللي عنده.
- ضغط الفيديو ياخذ تقريبًا نفس مدة الفيديو، وما يشتغل في Safari (يرسل الأصلي).
- اختيار مجلد الحفظ متوفر بس في Chrome وEdge على الكمبيوتر. باقي المتصفحات تستخدم تخزين المتصفح.
- الإشعارات على iPhone تشتغل بس إذا انضاف الموقع للشاشة الرئيسية (iOS 16.4+).
